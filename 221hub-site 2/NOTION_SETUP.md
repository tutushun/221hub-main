# Notion データベース セットアップガイド

## 1. Notion インテグレーションの作成

1. [Notion Integrations](https://www.notion.so/my-integrations) にアクセス
2. 「+ 新しいインテグレーション」をクリック
3. 以下を設定：
   - 名前: `221Hub Website`
   - ロゴ: 任意
   - 関連ワークスペース: あなたのワークスペース
4. 「送信」をクリック
5. 表示される「内部インテグレーションシークレット」をコピー
   → これが `NOTION_API_KEY` になります

## 2. Insights データベースの作成

Notionで新しいデータベースを作成し、以下のプロパティを設定してください：

| プロパティ名 | タイプ | 説明 |
|------------|--------|------|
| タイトル | タイトル | 記事のタイトル（日本語） |
| タイトル（英語） | テキスト | 記事のタイトル（英語） |
| スラッグ | テキスト | URL用の識別子（例: `market-trends-2026`） |
| カテゴリ | セレクト | 以下から選択 |
| カテゴリ（英語） | テキスト | カテゴリの英語表記 |
| 公開日 | 日付 | 記事の公開日 |
| 読了時間 | テキスト | 例: `8分で読める` |
| 読了時間（英語） | テキスト | 例: `8 min read` |
| リード文 | テキスト | 記事の概要（日本語） |
| リード文（英語） | テキスト | 記事の概要（英語） |
| 公開状態 | チェックボックス | ✓で公開 |

### カテゴリの選択肢

セレクトプロパティに以下を追加：
- 市場分析（青）
- テクノロジー（紫）
- 法規制（赤）
- 外国人支援（緑）
- 資産価値（オレンジ）
- 相続・資産（インディゴ）

## 3. データベースとインテグレーションの接続

1. 作成したデータベースを開く
2. 右上の「...」メニューをクリック
3. 「接続」→「221Hub Website」を選択
4. データベースのURLからIDを取得：
   ```
   https://notion.so/myworkspace/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...
                                 ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                 この32文字がデータベースID
   ```
   → これが `NOTION_INSIGHTS_DATABASE_ID` になります

## 4. 環境変数の設定

`.env.local` ファイルを作成：

```
NOTION_API_KEY=secret_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
NOTION_INSIGHTS_DATABASE_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
NEXT_PUBLIC_SITE_URL=https://221hub.com
```

## 5. 記事の書き方

### 新しい記事を追加する

1. データベースに新しい行を追加
2. 各プロパティを入力
3. ページを開いて本文を執筆
4. 「公開状態」にチェックを入れて公開

### 本文の書き方

Notionの通常の編集機能がそのまま使えます：

- **見出し**: H1, H2, H3 → 記事の見出しに変換
- **段落**: 通常のテキスト
- **箇条書き**: リストに変換
- **番号付きリスト**: 順序付きリストに変換
- **引用**: 引用ブロックに変換
- **コード**: コードブロックに変換
- **画像**: 記事内の画像として表示
- **テーブル**: テーブルとして表示

### 記事のプレビュー

1. ローカル開発サーバーを起動: `npm run dev`
2. `http://localhost:3000/insights/[スラッグ]` で確認

## 6. デプロイ後の運用

1. Notionで記事を追加・編集
2. Vercelが自動的に変更を検知してリビルド
3. 数分で本番サイトに反映

### ISR（Incremental Static Regeneration）

本番環境では、ページは60秒ごとに再生成されます。
つまり、Notionで変更してから最大1分で本番に反映されます。

## トラブルシューティング

### 記事が表示されない

1. 「公開状態」がチェックされているか確認
2. インテグレーションがデータベースに接続されているか確認
3. 環境変数が正しく設定されているか確認

### 画像が表示されない

Notionの画像URLは一時的なものなので、`next.config.js`でドメインを許可しています。
それでも表示されない場合は、画像を再アップロードしてください。
